# Метод градиентного спуска 1 порядка

Команда: 01

## Содержание каталога

В папке `src/` представлены скрипты, демонстрирующие работу градиентного спуска от базовой математики до применения в современных ML-фреймворках:

*   **`gd_numpy.py`** — ручная реализация градиентного спуска на чистом NumPy (матричные вычисления). Демонстрирует работу алгоритма «под капотом» на примере линейной регрессии.
*   **`gd_pytorch.py`** — индустриальная реализация с использованием механизма автоматического дифференцирования (Autograd) в PyTorch.
*   **`gd_bce.py`** — применение градиентного спуска для строго выпуклой задачи бинарной классификации. Реализация логистической регрессии с функцией потерь Binary Cross-Entropy.
*   **`gd_modifications.py`** — скрипт, демонстрирующий поведение алгоритма при различных модификациях и регуляризации.
*   **`*.png`** — сохраненные графики (визуализация аппроксимации и поверхностей ошибок), которые генерируются нашими скриптами и используются в презентации.

## Запуск кода

Для локального запуска скриптов необходимо убедиться, что у вас установлены нужные библиотеки. 

**1. Установка зависимостей**
Рекомендуется использовать виртуальное окружение. Установите необходимые пакеты командой:
```bash
pip install numpy torch matplotlib scikit-learn
```

**2. Выполнение скриптов**
Все скрипты являются самодостаточными. Вы можете запускать их из корневой директории проекта. При запуске скрипты автоматически сгенерируют датасеты, проведут обучение и выведут графики с результатами:

```bash
python src/gd_numpy.py
python src/gd_pytorch.py
python src/gd_bce.py
python src/gd_modifications.py
```
