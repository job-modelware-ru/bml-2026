# Метод K ближайших соседей

Команда: 02  
Участники: Дмитриенко Яна, Шабанова Арина

В проекте представлена собственная реализация алгоритма k-NN (k-Nearest Neighbors) на языке Python без использования сторонней библиотеки `sklearn`. Реализованы режимы классификации, регрессии и учет весов соседей по расстоянию.

## Содержание каталога

* `knn_presentation_02.pdf` — презентация доклада
* `readme.md` — описание проекта, структуры и инструкция по запуску
* `src/` — исходный код программы:
  * `src/knn.py` — функции вычисления расстояния, поиска соседей, классификации и регрессии
  * `src/main.py` — интерактивная консольная программа для демонстрации работы алгоритма
* `tests/` — модульные тесты:
  * `tests/test_knn.py` — тесты для проверки корректности вычислений

## Запуск кода

### Требования
* Python 3.8+ (сторонние зависимости не требуются, используются только встроенные модули).

### Запуск демонстрационной программы

Запуск из каталога проекта:

```bash
python src/main.py
```

После запуска в консоли можно выбрать:
1. **Классификацию** (вводятся координаты точки, параметр k и тип весов: uniform / distance).
2. **Регрессию** (оценка стоимости квартиры по ее площади).
0. **Выход** из программы.

Пример из презентации:
* Точки класса A: A1 = (1, 2), A2 = (2, 3), A3 = (2, 1)
* Точки класса B: B1 = (6, 4), B2 = (7, 5), B3 = (6, 6)
* Запрос: X = (3, 2), k = 3
* Результат: ближайшие соседи A2, A3, A1; прогноз — класс A.

### Запуск тестов

Для запуска автоматических тестов выполните:

```bash
python -m unittest discover -s tests -v
```
