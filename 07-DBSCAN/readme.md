# DBSCAN

Программа читает координаты точек из CSV-файла, распределяет точки по кластерам, определяет шумовые точки и сохраняет график результата.

## Структура проекта

- `src/dbscan.py` — реализация DBSCAN и функции поиска расстояний и соседей.
- `src/main.py` — запуск программы, выбор CSV-файла, ввод параметров и построение графика.
- `src/generate_data.py` — генерация трёх наборов данных.
- `src/points.csv` — набор для численного примера из презентации.
- `requirements.txt` — зависимости.


## Запуск

```bash
cd путь/к/проекту/DBSCAN
python -m pip install -r requirements.txt
python src/generate_data.py
python src/main.py
```
Программа покажет список CSV-файлов, расположенных в `src`. Введите номер нужного набора, затем значения `eps` и `min_samples`.

После выполнения программа покажет график и сохранит его в папку `src/results`. Если папки ещё нет, программа создаст её автоматически.

## Формат CSV

Каждая строка - точка, каждый столбец - её признак. Значения разделяются запятыми.
