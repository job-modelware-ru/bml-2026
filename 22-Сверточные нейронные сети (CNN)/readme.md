### Каталог `src/`

| Файл | Пункт | Что делает и что выводит |
| --- | --- | --- |
| `common.py` | — | Пути, палитра и стиль рисунков, фиксация случайности, сохранение результатов |
| `data.py` | — | Загрузка Fashion-MNIST, разбиение 55 000 / 5 000 / 10 000, нормализация, загрузчики мини-батчей |
| `models.py` | — | `SimpleCNN` (422 тыс. параметров), `TinyCNN` с глобальным усреднением (94 тыс.), `MLP`; таблица слоёв и параметров |
| `engine.py` | — | Цикл обучения и оценки (общий для всех сетей), сохранение и повторная загрузка обученных моделей |
| `01_why_cnn.py` | 1 | Картинка как матрица чисел; сдвиг на 2–3 пикселя меняет вектор пикселей сильнее, чем замена вещи на другую того же класса |
| `02_convolution_basics.py` | 1, 2 | Свёртка, padding, stride, пулинг на NumPy со сверкой с PyTorch (расхождение 7·10⁻¹⁵); классические ядра; число параметров свёрточного и полносвязного слоёв; эквивариантность к сдвигу; рецептивное поле; схемы для слайдов |
| `03_numerical_example.py` | 3 | Численный пример: свёртка 6×6 ядром 3×3 → ReLU → MaxPool → полносвязный слой → softmax; прямой и обратный проход вручную, шаг градиентного спуска, сверка градиентов с autograd PyTorch (расхождение ~10⁻¹⁶) |
| `04_train_cnn.py` | 2 | Основной пример: обучение `SimpleCNN` на Fashion-MNIST (12 эпох, Adam), кривые обучения, точность на тесте 92,1 % |
| `05_analyze_cnn.py` | 2 | Матрица ошибок, примеры ошибок, фильтры первого слоя, карты признаков, карта перекрытия (occlusion) |
| `06_compare_models.py` | 4 | Сравнение с логистической регрессией, случайным лесом, HOG + логистической регрессией, двумя MLP и `TinyCNN` (нейросети — по 3 запуска) |
| `07_inductive_bias.py` | 4 | Три эксперимента: устойчивость к сдвигу, перемешанные пиксели, обучение на 250…10 000 картинках |
| `08_architectures.py` | 4 | AlexNet → ResNet → EfficientNet → ViT → ConvNeXt: параметры и точность на ImageNet (метаданные torchvision) |
| `cnn_example.ipynb` | 2 | Самодостаточный блокнот: основной пример (данные → свёртка → модель → обучение → оценка → карты признаков) с пояснениями всех терминов; читается сверху вниз без других файлов |
| `run_all.py` | — | Запускает все скрипты по порядку и пересобирает `figures/` и `results/` |
| `requirements.txt` | — | Зависимости |
| `figures/` | — | Рисунки для слайдов (PNG и векторные SVG) |
| `results/` | — | Все числа из презентации в JSON; `results/models/` — веса обученных сетей (не хранятся в git) |

Каждый скрипт самодостаточен: запускается отдельно, печатает пояснения и результаты
в консоль, сохраняет рисунки в `figures/` и числа в `results/`. Обученные модели
сохраняются, поэтому скрипты, которым нужны одни и те же сети, не обучают их повторно.

## Запуск кода

```bash
cd src
pip install -r requirements.txt

python run_all.py                  # всё по порядку (≈ 1,5 ч на процессоре, несколько минут на GPU)
python run_all.py 01 02 03 04 05   # без долгих сравнений (≈ 10 мин на процессоре)
python 04_train_cnn.py             # или любой скрипт по отдельности
python 06_compare_models.py --seeds 1   # сравнение с одним запуском на модель вместо трёх
```

Набор данных Fashion-MNIST (~30 МБ) скачивается автоматически при первом запуске в `src/data/`.
Видеокарта используется автоматически, если доступна (`torch.cuda.is_available()`).
