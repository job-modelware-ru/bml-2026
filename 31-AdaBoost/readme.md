| `src/` | Исходный код |
| `readme.md` | - |

### Каталог `src/`

| Файл | Что внутри |
|---|---|
| `AdaBoost.py` | Собственная реализация AdaBoost для бинарной классификации (классы `WeightedStump` и `MyAdaBoost`, только numpy) |
| `frogs.py` | Генератор синтетических данных о лягушках: ядовитая или безвредная (яркость окраски, длина тела, дальность прыжка и др.) |
| `simple-ex.py` | Численный пример из презентации: 14 лягушек (L — длина тела, B — яркость), 3 итерации; выводит таблицы E(+)/E(−) по порогам, ε, α, e^±α, Z, новые веса и итоговую таблицу, строит рисунок с пнями |
| `exp-decay.py` | Показывает экспоненциальное убывание ошибки: сравнивает ошибку обучения, потерю ∏Zₜ и границу exp(−2Σγₜ²), строит график |
| `compare-methods.py` | Сравнивает свой AdaBoost с AdaBoost из sklearn, GradientBoosting, XGBoost, Random Forest и логистической регрессией; проверяет устойчивость к шуму в метках, строит график ошибки на тесте |
| `run_all.py` | По очереди запускает `simple-ex.py`, `exp-decay.py` и `compare-methods.py` |
| `requirements.txt` | Зависимости |

## Запуск кода

```
cd src
pip install -r requirements.txt

python run_all.py            # все скрипты по порядку
python simple-ex.py          # или любой скрипт по отдельности
```

Графики открываются в окне и сохраняются в `src/figures/`.
