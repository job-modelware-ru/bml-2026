# Подбор одного гиперпараметра с помощью GridSearchCV

**Предмет:** Основы машинного обучения  
**Тема:** Подбор одного гиперпараметра с помощью `GridSearchCV`

## Цель

Показать, как автоматически выбрать **один гиперпараметр** модели машинного обучения по результатам кросс-валидации и затем независимо проверить результат на тестовой выборке.

## Данные и модель

- **Данные:** встроенный в `scikit-learn` набор `Breast Cancer Wisconsin` (569 объектов, 30 числовых признаков, 2 класса). Интернет для загрузки данных не требуется.
- **Алгоритм:** `DecisionTreeClassifier` (дерево решений).
- **Подбираемый гиперпараметр:** только `max_depth` — максимальная глубина дерева.
- **Сетка:** значения `1, 2, ..., 15`.
- **Метод:** `GridSearchCV`, 5-кратная стратифицированная кросс-валидация, целевая метрика — `accuracy`.
- **Разделение:** 75% на обучение и подбор, 25% на независимое тестирование; `random_state=42`.

## Этапы решения

1. Загрузка и изучение данных.
2. Деление на train/test со стратификацией.
3. Обучение дерева решений без подбора (`max_depth=None`).
4. Перебор одной настройки `max_depth` с `GridSearchCV` на обучающей выборке.
5. Таблица и график средней точности на обучающих и валидационных фолдах.
6. Оценка лучших моделей на отложенном тесте: accuracy, precision, recall, F1 и матрицы ошибок.
7. Выводы о недообучении, переобучении и выборе метрики.

## Как запустить

1. Установить Python 3.10+.
2. Открыть терминал в каталоге задания (там, где лежит `requirements.txt`).
3. Создать виртуальное окружение:

   ```bash
   python -m venv .venv
   ```

4. Активировать его (Windows PowerShell):

   ```powershell
   .\.venv\Scripts\Activate.ps1
   ```

   Или в Linux / macOS:

   ```bash
   source .venv/bin/activate
   ```

5. Установить зависимости и запустить ноутбук:

   ```bash
   python -m pip install -r requirements.txt
   jupyter notebook src/solution.ipynb
   ```

6. В Jupyter выполнить **Run All Cells**. Таблицы и графики появятся прямо в ноутбуке.
