# Сравнение RobustScaler и StandardScaler при наличии выбросов

Индивидуальная работа по машинному обучению. Исследуется, как искусственные выбросы влияют на масштабирование числовых признаков и на качество классификации методом **k ближайших соседей (KNN)**.

Весь ход исследования — краткая теория, Python-код, визуализации, таблицы и интерпретация результатов — собран в `src/scaler_comparison.ipynb`.

## Описание решения

1. Генерируются синтетические данные для бинарной классификации с четырьмя числовыми признаками разного масштаба.
2. Данные делятся на обучающую (75%) и тестовую (25%) части **до** внесения выбросов.
3. В обучающую часть добавляются выбросы во второй признак: **0%, 5%, 10% и 20%** объектов. Тестовая выборка остаётся неизменной.
4. Сравниваются `StandardScaler` (среднее и стандартное отклонение) и `RobustScaler` (медиана и межквартильный размах): их параметры и изменение координат одних и тех же тестовых объектов.
5. Для каждого уровня загрязнения обучается KNN (`n_neighbors=7`) со `StandardScaler`, с `RobustScaler` и без масштабирования. Качество оценивается по **Accuracy** и **F1-score** на одной и той же чистой тестовой выборке.

Масштабирование выполняется только на обучающих данных с помощью `Pipeline` из scikit-learn, чтобы избежать утечки информации из тестовой выборки.

## Используемые данные

- **Источник:** искусственный набор, сгенерированный функцией `sklearn.datasets.make_classification`; внешние файлы не нужны.
- **Объём:** 1200 объектов, 4 числовых признака, 2 класса.
- **Разделение:** 900 объектов для обучения и 300 для тестирования; стратифицированное разбиение.
- **Разный исходный масштаб:** признаки дополнительно умножаются на коэффициенты `1.0`, `15.0`, `0.2`, `4.0`.
- **Выбросы:** в 0%, 5%, 10% и 20% обучающих объектов второй признак изменяется на большую положительную или отрицательную величину (30 стандартных отклонений исходного второго признака).
- **Воспроизводимость:** `random_state=42`; индексы и направления искусственных выбросов фиксированы.

## Полученные результаты

При загрязнении 20% обучающих объектов показатель масштаба второго признака у `StandardScaler` изменился с **13,569 до 182,433** (примерно в **13,4 раза**). У `RobustScaler` межквартильный размах изменился с **16,294 до 21,869** (примерно в **1,34 раза**).

Среднее абсолютное изменение координат чистых тестовых объектов относительно преобразования, обученного на данных без выбросов, при 20% загрязнения: **0,1626** для `StandardScaler` и **0,0380** для `RobustScaler`. Это разные преобразованные шкалы, поэтому показатель отражает устойчивость каждого способа относительно собственного базового варианта.

**F1-score KNN на тестовой выборке:**

| Доля выбросов в train | Без масштабирования | StandardScaler | RobustScaler |
|---|---:|---:|---:|
| 0% | 0,8874 | 0,9135 | **0,9172** |
| 5% | 0,8867 | 0,8919 | **0,9141** |
| 10% | 0,8837 | 0,9037 | **0,9066** |
| 20% | 0,8874 | 0,8940 | **0,9178** |

**Вывод:** в рассматриваемом эксперименте `RobustScaler` заметно устойчивее по параметрам масштабирования и даёт более высокий F1 для KNN при всех проверенных долях выбросов. Однако более устойчивое масштабирование **не гарантирует** улучшение качества любой модели на любом датасете. Ограничения работы: синтетические данные, изменения только одного признака, одно разбиение train/test и фиксированные гиперпараметры KNN.

## Инструкция по запуску

Понадобится **Python 3.10+** и Jupyter Notebook или JupyterLab.

1. Клонировать репозиторий или открыть терминал в уже скачанном репозитории. Из корня `bml-2026` перейти в каталог индивидуальной работы:

   ```bash
   cd individual-assignments/21-Ятманова-Анна
   ```

2. Установить зависимости:

   ```bash
   python -m pip install -r requirements.txt
   ```

3. Запустить Jupyter:

   ```bash
   jupyter notebook src/scaler_comparison.ipynb
   ```

4. В открывшемся ноутбуке выбрать **Kernel → Restart & Run All** (или **Run All**). Все таблицы, графики и вычисляемые выводы сформируются автоматически.

Можно также открыть файл в VS Code с установленным расширением Jupyter.
