# Построение кривой обучения классификатор (Learning Curves)

## Тема задания

Анализ классических кривых обучения для различных алгоритмов машинного обучения с целью диагностики переобучения и выбора оптимальных моделей в зависимости от структуры данных.

## Краткое описание решения

В рамках проекта реализован комплексный пайплайн для тестирования алгоритмов классификации:

1. **Генерация данных.** 
Разработан класс с функциями `SyntheticDataset`, который генерирует 5 уникальных типов данных:

   * Линейно разделимые
   * Стандартные бинарные
   * Несбалансированные
   * Многоклассовые
   * Нелинейные (вложенные кольца)
2. **Анализ датасетов.** 
Реализована визуализация многомерной структуры синтетических данных с помощью метода главных компонент.
3. **Обучение и валидация.**
Написан функционал для прогона пула из 8 алгоритмов (`LogisticRegression`, `RandomForestClassifier`, `AdaBoostClassifier`, `SVC` и др.). Для оценки стабильности применяется метод Монте-Карло кросс-валидация (`train\_test\_split` с различными seed-значениями и усреднением метрик).
4. **Визуализация.**
Построена сетка графиков для каждой модели, отображающая динамику метрики `balanced\_accuracy` на обучающей (Train) и тестовой (Test) выборках в зависимости от объема данных.

## Используемые данные

Проект использует исключительно синтетические данные, сгенерированные с помощью встроенных инструментов библиотеки `scikit-learn`: `sklearn.datasets.make\_classification` и `sklearn.datasets.make\_circles`.

## Полученные результаты

* Наглядно продемонстрировано, что алгоритмы на основе деревьев решений (`DecisionTreeClassifier`, `RandomForestClassifier`) со стандартными гиперпараметрами склонны к зазубриванию данных (Train score = 1.0), что ведет к увеличению разрыва (generalization gap) между тренировочной и тестовой выборками.
* Установлено, что эффективность моделей критически зависит от природы данных:

  * для стандартных бинарных задач наилучшую способность к обобщению показал алгоритм `SVC`.
  * на данных с сильным дисбалансом классов (90/10) базовые линейные модели полностью провалились (score \~0.5), в то время как ансамблевый метод `AdaBoost` оказался единственным, кто смог выявить закономерности "из коробки".
