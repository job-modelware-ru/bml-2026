# Построение кривых обучения классификаторов (Learning Curves)

**Тема:** Анализ кривых обучения для алгоритмов классификации. Цель — диагностика переобучения и выбор оптимальных моделей под конкретную структуру данных.

## Что внутри

Пайплайн тестирования алгоритмов разбит на несколько этапов:

* **Генерация данных**: Класс `SyntheticDataset` создает 5 типов выборок через `sklearn.datasets` (`make_classification`, `make_circles`): линейно разделимые, стандартные бинарные, с дисбалансом классов (90/10), многоклассовые и нелинейные (вложенные кольца).
* **Анализ**: Многомерная структура датасетов визуализируется в 2D с помощью метода главных компонент (PCA).
* **Обучение и валидация**: Прогон 8 классификаторов (вкл. `LogisticRegression`, `RandomForest`, `AdaBoost`, `SVC`). Стабильность оценивается через кросс-валидацию Монте-Карло — многократный `train_test_split` с разными seed и усреднением метрики `balanced_accuracy`.
* **Визуализация**: Сетка графиков динамики `balanced_accuracy` (Train vs Test) в зависимости от объема выборки.

## Инсайты и результаты

Модели ведут себя ожидаемо по-разному в зависимости от природы данных:

1. **Деревья решений и лес** (`DecisionTreeClassifier`, `RandomForestClassifier`) со стандартными гиперпараметрами моментально переобучаются (Train score = 1.0) — на графиках виден огромный generalization gap.
2. **Стандартная бинарная классификация**: Лучшую обобщающую способность показал метод опорных векторов (`SVC`).
3. **Дисбаланс классов (90/10)**: Базовые линейные модели предсказуемо провалились (score ~0.5). `AdaBoost` оказался единственным алгоритмом, адекватно уловившим закономерности прямо "из коробки".
