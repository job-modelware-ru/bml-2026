# Сравнение macro-F1 и weighted-F1

## Описание

Цель — выяснить, чем macro-F1 и weighted-F1 отличаются при многоклассовой классификации: когда их значения близки, когда расходятся и как это сказывается на сравнении классификаторов.

Обе метрики усредняют один и тот же набор значений F1 по классам и отличаются только весами:

- macro-F1: `M = (1/K) · Σ F1_k`, все классы равноправны;
- weighted-F1: `W = Σ p_k · F1_k`, где `p_k = n_k / N` — доля класса среди истинных меток (веса берутся из `y_true`, а не из предсказаний).

Разность метрик определяется тождеством `W − M = Σ (p_k − 1/K) · F1_k = K · Cov(p_k, F1_k)`. При равном количестве объектов каждого класса метрики совпадают. При дисбалансе weighted-F1 может быть как выше, так и ниже macro-F1.

В работе реализован собственный расчёт метрик, исследовано влияние распределения классов и проведено сравнение классификаторов на реальных данных.

## Собственная реализация и проверка

Метрики реализованы на NumPy без использования готовых функций scikit-learn. Реализация включает построение матрицы ошибок, расчёт precision, recall, F1 по классам и вычисление macro-F1 и weighted-F1.

Корректность проверена сравнением со scikit-learn на случайных и граничных примерах. Пройдено 12 тестов, выполнено 2012 сравнений. Максимальное абсолютное расхождение составило 3.331e-16.

## Данные

- E1a и E1b — матрицы ошибок, заданные вручную или рассчитанные детерминированно. Случайность не используется.
- E2 — `load_wine` из scikit-learn: 178 объектов, 13 признаков, 3 класса (59, 71 и 48 объектов). Данные встроены в sklearn, скачивать ничего не нужно.

## Результаты

### E1a. Три показательных случая

| Случай | N | accuracy | macro-F1 | weighted-F1 | W − M |
|---|---|---|---|---|---|
| A. Классификатор всегда предсказывает большинство (95/5) | 1000 | 0.9500 | 0.4872 | 0.9256 | 0.4385 |
| B. Три класса по 100 объектов, с ошибками | 300 | 0.7333 | 0.7289 | 0.7289 | 0.0000 |
| C. Два крупных трудных класса и один редкий лёгкий | 820 | 0.5122 | 0.6667 | 0.5122 | −0.1545 |

В случае A weighted-F1 остаётся высоким (0.9256), хотя редкий класс вообще не распознаётся. В случае B метрики совпадают из-за равного количества объектов каждого класса. Случай C показывает, что weighted-F1 может быть ниже macro-F1, если редкий класс распознаётся лучше многочисленных.

### E1b. Влияние дисбаланса

Исследована бинарная классификация при фиксированных TPR = 0.8 и FPR = 0.05. Доля редкого класса изменялась от 50% до 0.5% при общем количестве 100 000 объектов.

| Доля редкого класса | macro-F1 | weighted-F1 | F1 редкого класса |
|---|---|---|---|
| 50% | 0.8743 | 0.8743 | 0.8649 |
| 0.5% | 0.5550 | 0.9697 | 0.1362 |

При уменьшении доли редкого класса macro-F1 снижается, а weighted-F1 растёт. Даже при неизменных TPR и FPR значение F1 редкого класса зависит от его распространённости.

Полные результаты и график зависимостей представлены в `src/solution.ipynb`.

### E2. Обучение моделей на wine

Использован набор `wine` из scikit-learn: 178 объектов, 13 признаков и 3 класса. Сравнивались DummyClassifier, LogisticRegression и DecisionTreeClassifier с заранее заданными параметрами.

Предсказания получены с помощью стратифицированной кросс-валидации на пяти частях (`StratifiedKFold` и `cross_val_predict`). Метрики рассчитаны по объединённым предсказаниям и сверены со scikit-learn.

| Модель | Accuracy | macro-F1 | weighted-F1 | W − M |
|---|---|---|---|---|
| Dummy | 0.3989 | 0.1901 | 0.2275 | +0.0374 |
| Logistic Regression | 0.9831 | 0.9826 | 0.9832 | +0.0006 |
| Decision Tree | 0.8764 | 0.8794 | 0.8768 | −0.0026 |

Обе метрики дали одинаковый порядок моделей. У Logistic Regression и Decision Tree различия между macro-F1 и weighted-F1 небольшие из-за умеренного дисбаланса классов и близких значений F1 по классам. При этом у дерева weighted-F1 оказалась немного ниже macro-F1.

## Выводы

1. Macro-F1 и weighted-F1 — два способа усреднить одни и те же F1 классов. Разность между ними равна `K · Cov(p_k, F1_k)`: она нулевая при равных долях классов и может иметь любой знак.
2. При сильном дисбалансе (E1b) метрики могут двигаться в противоположные стороны при неизменном классификаторе: weighted-F1 и accuracy растут за счёт большинства, macro-F1 падает вслед за F1 редкого класса. Сам F1 зависит от распространённости класса, поэтому при сравнении macro-F1 на выборках с разными долями классов это нужно учитывать.
3. На `wine` с умеренным дисбалансом метрики дают одинаковый порядок моделей, а различие между ними мало и объясняется тождеством.
4. Лучшей метрики «вообще» нет: weighted-F1 отражает качество в среднем по объектам, macro-F1 — в среднем по классам. Выбор зависит от того, насколько важны редкие классы, и полезно смотреть F1 по классам.

Эксперименты E1a и E1b основаны на искусственно заданных матрицах ошибок и показывают математические свойства метрик.

Для работы необходим Python и библиотеки из `requirements.txt`.

```bash
pip install -r requirements.txt
```

```bash
cd src
```

Запустить тесты:

```bash
python test_f1_metrics.py
```

Открыть ноутбук с экспериментами:

```bash
jupyter notebook solution.ipynb
```

В Jupyter выполнить все ячейки последовательно (Run All). Набор данных `wine` входит в состав scikit-learn и не требует отдельной загрузки.
