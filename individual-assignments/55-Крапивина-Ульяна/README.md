# Определение языка короткого текста по символьным n-граммам

## Тема задания
Разработка и исследование классификатора для автоматического определения языка короткого текста (слов, фраз, сообщений, отзывов) на основе символьных n-грамм (char n-grams) и TF-IDF с линейными моделями машинного обучения.

## Краткое описание решения
В основе решения лежит гипотеза, что **символьные n-граммы** (подстроки длиной 2–4 символа) эффективнее классического word-level подхода для коротких текстов, так как они:
- Устойчивы к опечаткам и искажениям (не требуют точного совпадения слов).
- Не требуют токенизации, лемматизации и словарей.
- Хорошо работают на фрагментах текста (5–20 символов), где слова еще не сформированы.

**Пайплайн решения:**
1. Предобработка: `TfidfVectorizer` с `analyzer='char_wb'` (учитывает границы слов), `ngram_range=(2, 4)`, `min_df=5`, `sublinear_tf=True`.
2. Классификация: `LinearSVC` (C=1.0).
3. Сравнение: базовый `MultinomialNB`, `LogisticRegression` и `LinearSVC`.
4. Эксперименты:
   - Сравнение с word-level TF-IDF на текстах разной длины (от 5 до 200 символов).
   - Проверка устойчивости к искусственным опечаткам (замена, удаление, перестановка).
   - Интерпретация весов модели (какие n-граммы «узнают» язык).
   - Эксперимент с транслитерацией (влияние алфавита).

## Используемые данные
- **Датасет:** [`papluca/language-identification`](https://huggingface.co/datasets/papluca/language-identification) (Hugging Face).
- **Домен:** короткие тексты и отзывы.
- **Выбранные языки (8):** `en` (английский), `fr` (французский), `de` (немецкий), `es` (испанский), `it` (итальянский), `ru` (русский), `pt` (португальский), `nl` (нидерландский).
- **Размеры выборок после фильтрации:**
  - Train: 28 000 (по 3 500 на язык).
  - Validation: 4 000 (по 500).
  - Test: 4 000 (по 500).
- **Ограничение:** в тестовой выборке обнаружено 111 совпадений с train (2.8%), что может давать завышение accuracy порядка 0.3 п.п. (описано в отчёте).

## Полученные результаты

| Метрика | Значение |
|---|---|
| **Accuracy (test)** | **0.9990** |
| **Macro-F1 (test)** | **0.9990** |
| Количество ошибок | 4 из 4 000 (0.10%) |

**Ключевые выводы:**
- **На полных текстах** `LinearSVC` (0.9995) > `LogReg` (0.9985) > `MNB` (0.9975) на validation.
- **На коротких текстах (5 символов):** char n-grams — **0.769**, word-level — 0.638 (**+13.1 п.п.**).
- **При 30% опечаток:** char n-grams — **0.944**, word-level — 0.680 (**+26.4 п.п.**).
- **При 50% опечаток:** char n-grams — **0.704**, word-level — 0.342 (**+36.2 п.п.**).
- **Интерпретируемость:** модель выучивает валидные признаки (`'ão'` для pt, `'ción'` для es, `'zione'` для it, `'ij'` для nl).
- **Роль алфавита:** при транслитерации `ru` в латиницу точность падает с 1.000 до 0.000 (модель зависит от алфавита, а не только от языковых паттернов).

**Ошибки модели (4 шт.):**
1. `exactamente como descrito` (es → pt) — объективная неоднозначность.
2. `Rev's Early Reads: 2 marzo` (it → en) — смешанный язык.
3. `Talvez isto possa funcionar para si.` (pt → es) — слабый сигнал в редких словах.
4. `Le tombe segnalate da Albuquerque...` (it → pt) — имена собственные.
