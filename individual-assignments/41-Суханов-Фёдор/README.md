# Влияние `max_features` в Random Forest

Индивидуальная работа по курсу «Основы машинного обучения». Работа развивает [демонстрацию из учебного репозитория](https://github.com/job-modelware-ru/bml-2026/blob/main/17-%D0%A1%D0%BB%D1%83%D1%87%D0%B0%D0%B9%D0%BD%D1%8B%D0%B9%20%D0%BB%D0%B5%D1%81/src/02_max_features.py), где сравниваются лишь два варианта случайного леса.

## Задача и гипотеза

`max_features` задаёт, сколько случайно выбранных признаков дерево рассматривает **при каждом разбиении узла**. При малом значении деревья обычно менее похожи друг на друга, но отдельные разбиения могут быть слабее. При большом значении дерево чаще находит сильный признак, однако прогнозы деревьев могут стать более похожими. Поэтому качество леса нужно проверять на данных, а не выбирать параметр только по теории.

## Данные и метод

- Набор `breast_cancer` из `scikit-learn`: 569 объектов, 30 числовых признаков, два класса.
- Стратифицированное разделение на обучение (80%) и отложенный тест (20%).
- На обучающей части: `StratifiedKFold` с 5 фолдами. Сравниваются `max_features = 1, 2, 4, 5, 8, 12, 16, 24, 30`. Значение 5 соответствует `sqrt(30)`; 30 означает все признаки.
- Остальные настройки одинаковы: 120 деревьев, `bootstrap=True`, `random_state=42`. Масштабирование признаков деревьям не требуется.
- Для каждого значения измеряются средние по фолдам accuracy, ROC-AUC, accuracy на обучении, время обучения и попарная корреляция прогнозов деревьев **на валидационной части**. Разброс accuracy и ROC-AUC указан как стандартное отклонение по фолдам.
- Лучшее значение выбирается по среднему CV ROC-AUC. Только затем лес обучается на всей обучающей части и оценивается на отложенном тесте.

Средняя корреляция — показатель сходства прогнозов деревьев, а не прямая оценка качества модели. У отдельного дерева с постоянным прогнозом корреляция не определена; такие деревья исключаются из расчёта.

## Запуск

Требуется Python 3.10+ и библиотеки из `requirements.txt`:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python src/solution.py
```

Для быстрой проверки можно использовать `python src/solution.py --n-estimators 20 --folds 3`. Параметры командной строки можно посмотреть через `--help`.

Скрипт выводит таблицу метрик и сохраняет `results/cv_results.csv` и `results/max_features.png`. Запуск повторяем благодаря фиксированному `random_state`; время обучения зависит от компьютера.

## Результат стандартного запуска

Запуск с `scikit-learn 1.9.1` дал следующие ориентиры:

| `max_features` | CV accuracy | CV ROC-AUC | Средняя корреляция деревьев |
|---:|---:|---:|---:|
| 1 | 0.9626 | 0.9901 | 0.6910 |
| 5 (`sqrt`) | 0.9648 | 0.9896 | 0.7877 |
| 30 (все признаки) | 0.9560 | 0.9886 | 0.8178 |

По среднему CV ROC-AUC выбран `max_features=1`. На отложенном тесте получены accuracy **0.9561** и ROC-AUC **0.9916** (5 ошибок из 114 объектов). Полные результаты для всех девяти значений находятся в `results/cv_results.csv`, график — в `results/max_features.png`.

## Вывод

При увеличении `max_features` деревья стали заметно более похожими по прогнозам. Различия ROC-AUC между вариантами малы по сравнению с разбросом между фолдами, поэтому результат не доказывает, что значение 1 в целом лучше 5 или 30. Для этого набора данных и выбранной схемы проверки оно лишь получило наибольшее среднее CV ROC-AUC. Оптимальное значение зависит от данных и выбранной метрики.
