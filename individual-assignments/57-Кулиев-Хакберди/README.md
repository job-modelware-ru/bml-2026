# Подбор числа кластеров методом локтя

В ноутбуке сравнивается инерция K-means при числе кластеров от 1 до 10. Данные содержат 300 двумерных точек, сгенерированных вокруг трёх центров с помощью `make_blobs`.

Кривая инерции заметно выравнивается при трёх кластерах. При переходе от двух кластеров к трём инерция падает примерно на 3066,0, а при добавлении четвёртого — на 55,6. Выбранное число совпадает с числом групп, заданным при генерации.

## Запуск

В окружении, которое используется ядром Jupyter, установите зависимости:

```bash
python -m pip install -r requirements.txt
```

Откройте [ноутбук](src/solution.ipynb) в Jupyter и выполните все ячейки сверху вниз.
