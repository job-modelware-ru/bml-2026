# Классификация рукописных цифр методом k ближайших соседей (KNN)

## 1. Цель работы

Изучить алгоритм k ближайших соседей (K-Nearest Neighbors, KNN) и применить его для классификации изображений рукописных цифр от 0 до 9.

## 2. Описание задачи

Необходимо разработать программу на Python для распознавания рукописных цифр методом k ближайших соседей.

В рамках работы решены следующие задачи:

1. Загрузка и исследование набора данных рукописных цифр.
2. Самостоятельная реализация алгоритма KNN с использованием NumPy.
3. Разделение данных на обучающую, валидационную и тестовую выборки.
4. Исследование влияния количества соседей на точность классификации.
5. Подбор оптимального значения параметра k.
6. Оценка качества классификации на тестовой выборке.
7. Построение матрицы ошибок и визуализация результатов.
8. Сравнение собственной реализации с KNeighborsClassifier из Scikit-learn.

## 3. Используемые данные

Для обучения и тестирования модели используется набор данных Digits из библиотеки Scikit-learn.

Характеристики датасета:

- Количество изображений: 1797.
- Количество классов: 10 (цифры от 0 до 9).
- Размер изображений: 8×8 пикселей.
- Количество признаков: 64.
- Диапазон значений пикселей: от 0 до 16.

Данные разделены на три выборки:

- Обучающая — 64%.
- Валидационная — 16%.
- Тестовая — 20%.

## 4. Реализация алгоритма

Алгоритм KNN реализован самостоятельно на языке Python.

Для определения близости изображений используется евклидово расстояние.

Процесс классификации включает следующие этапы:

1. Вычисление расстояний от классифицируемого изображения до всех изображений обучающей выборки.
2. Поиск k ближайших изображений.
3. Определение классов найденных соседей.
4. Выбор наиболее часто встречающегося класса.
5. Возвращение предсказанной цифры.

Для выбора оптимального значения параметра k проведены эксперименты при k от 1 до 15.

Качество модели оценивается с помощью метрик Accuracy, Precision, Recall и F1-score.

Дополнительно построены графики зависимости точности от количества соседей, матрица ошибок и визуализации правильно и ошибочно классифицированных изображений.

## 5. Результаты экспериментов

В результате исследования установлено, что оптимальное количество соседей составляет **k = 2**.

Точность классификации на валидационной выборке составила **98,61%**.

Результаты на тестовой выборке:

| Показатель | Значение |
|---|---|
| Оптимальное количество соседей | 2 |
| Количество тестовых изображений | 360 |
| Правильно классифицировано | 355 |
| Количество ошибок | 5 |
| Accuracy | 98,61% |
| Accuracy Scikit-learn | 98,61% |
| Совпадение предсказаний двух реализаций | 100% |

Анализ матрицы ошибок показал, что цифры 0, 2, 3, 5, 6 и 7 распознаны без ошибок. Наибольшие сложности возникли при распознавании цифр 8 и 9.

Результаты собственной реализации KNN полностью совпали с результатами классификатора Scikit-learn на тестовой выборке.
