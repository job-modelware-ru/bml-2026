# Сравнение accuracy и F1 при дисбалансе классов

Индивидуальное задание по машинному обучению. Григорьева Анастасия, № 07.

## Задача и данные

Сравниваем классификатор ближайшего центра и базовую модель «всегда 0» на пяти тестах с разной долей класса 1. Данные синтетические и генерируются в ноутбуке из N(0, 1) и N(2, 1) с фиксированными начальными состояниями генераторов. Обучение проходит один раз на сбалансированной выборке. Каждый тест содержит 10 000 объектов, а F1 рассчитывается для класса 1.

## Результаты

| Доля класса 1 | Модель | Accuracy | F1 |
|---:|---|---:|---:|
| 50% | Всегда 0 | 0.500 | 0.000 |
| 50% | Ближ. центр | 0.844 | 0.845 |
| 20% | Всегда 0 | 0.800 | 0.000 |
| 20% | Ближ. центр | 0.842 | 0.680 |
| 10% | Всегда 0 | 0.900 | 0.000 |
| 10% | Ближ. центр | 0.840 | 0.509 |
| 5% | Всегда 0 | 0.950 | 0.000 |
| 5% | Ближ. центр | 0.841 | 0.345 |
| 1% | Всегда 0 | 0.990 | 0.000 |
| 1% | Ближ. центр | 0.842 | 0.093 |

При 1% положительных примеров базовая модель получает accuracy 0.990 и F1 0.000. Она пропускает все 100 единиц. Классификатор ближайшего центра находит 81 из 100, но даёт 1565 ложных тревог. Его accuracy равна 0.842, а F1 — 0.093. При 1% accuracy выбирает базовую модель, а F1 класса 1 — классификатор ближайшего центра.

У ближайшего центра recall при 1% составляет 0.810, а precision — 0.049. Даже при высоком recall многочисленный класс 0 даёт много ложных тревог. Из-за этого падают precision и F1. Для задачи, в которой важно находить редкие события, полезно показывать F1 вместе с precision, recall и числом ошибок каждого типа. Если ошибки имеют разные последствия, решение также зависит от их стоимости.

Ограничения: синтетические данные, один признак, один запуск и фиксированная граница решения. Эксперимент меняет баланс только на тесте. Он не измеряет эффект дисбаланса при обучении или статистическую неопределённость оценок.

## Запуск

Требуется Python 3.10 или новее. Сам эксперимент использует стандартную библиотеку. Для открытия и выполнения ноутбука установите JupyterLab, если его ещё нет.

```bash
python -m pip install -r requirements.txt
python -m jupyterlab src/solution.ipynb
```

В JupyterLab выберите **Run → Restart Kernel and Run All Cells**. Ноутбук повторно выведет таблицу метрик и матрицы ошибок. Исходные результаты уже сохранены в ячейках вывода.
