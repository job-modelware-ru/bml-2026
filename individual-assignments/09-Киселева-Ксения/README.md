# Сравнение линейной модели и дерева на данных make_moons

## Задача

Сравнить поведение линейной модели и дерева на данных `make_moons`.

## Данные

Синтетический набор `sklearn.datasets.make_moons`:
- 500 объектов, 2 признака, 2 класса;
- `noise=0.25`, `random_state=42`;
- разбиение на train/test: 70/30, стратифицированное (`random_state=42`).

Данные нелинейно разделимы: два «полумесяца» пересекаются, и линейная граница не может разделить классы без ошибок.

## Что сделано

1. Сгенерированы данные `make_moons`, выполнено train/test-разбиение, построена визуализация классов.

2. **Линейная модель** - `LogisticRegression`:
   - обучение на train, оценка accuracy на train/test;
   - визуализация линейной границы решения;
   - показано, что модель не переобучается (train = test), но и не решает задачу полностью (accuracy = 0.84).

3. **Дерево решений** - `DecisionTreeClassifier` с разными `max_depth` (1, 2, 3, 5, 10, None):
   - для каждой глубины - accuracy на train/test;
   - визуализация 6 границ решения;
   - построена кривая переобучения: при `max_depth >= 10` train accuracy = 1.0, test стабилизируется на 0.95.

4. **Сравнение** - сводная таблица accuracy и разрыва train–test.

5. **Влияние шума** - при `noise = 0.1 … 0.5` обе модели теряют точность; дерево (depth=5) стабильно лучше линейной модели при малом шуме, но при `noise = 0.5` проигрывает ей (0.787 vs 0.820), так как переобучается на шумовых выбросах.

6. **Полиномиальные признаки** для линейной модели (`PolynomialFeatures(degree=3)`):
   - accuracy вырастает с 0.84 до 0.93;
   - граница решения становится нелинейной.

## Результаты

## Выводы

**Линейная модель (LogisticRegression):**
- строит прямую границу решения;
- accuracy = 0.84 на `make_moons` - задача нелинейная, прямая не разделяет классы;
- не переобучается, устойчива к шуму (accuracy падает медленно), но принципиально ограничена;
- с полиномиальными признаками accuracy растёт до 0.93 - это уже не «чистая» линейная модель.

**Дерево решений:**
- строит кусочно-постоянную границу (прямоугольники);
- уже при `max_depth=2` обгоняет логистическую регрессию;
- оптимум - `max_depth=5`: test accuracy = 0.95 без переобучения;
- при `max_depth >= 10` - переобучение: train=1.0, test не растёт, разрыв train−test растёт;
- чувствительно к шуму: при `noise=0.5` accuracy падает до 0.79 - ниже, чем у линейной модели, из-за переобучения на выбросы.

**Практический вывод:**
- для линейно разделимых данных линейная модель проще, устойчивее и не переобучается;
- для нелинейных данных (как `make_moons`) дерево подходит лучше, но требует контроля сложности (`max_depth`, `min_samples_leaf`);
- выбор модели зависит от природы данных, а не от «сложности» алгоритма.
