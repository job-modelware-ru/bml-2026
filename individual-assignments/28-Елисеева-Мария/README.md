# Применение Bernoulli Naive Bayes к бинаризованным признакам

## Краткое описание решения

Bernoulli Naive Bayes — наивный байесовский классификатор для бинарных признаков `x_j ∈ {0, 1}`. Он моделирует `P(x_j = 1 | y = k) = θ_kj` и выбирает класс с наибольшей апостериорной вероятностью, считая признаки независимыми. Оценка параметров со сглаживанием Лапласа: `θ_kj = (N_kj + α) / (N_k + 2α)`. Отсутствие признака (`x_j = 0`) тоже вносит вклад через `log(1 − θ_kj)`.

В работе (`src/solution.ipynb`):

1. Изложена теория модели и бинаризации.
2. Модель реализована с нуля (`src/bernoulli_nb.py`, только NumPy) и сверена с `sklearn.naive_bayes.BernoulliNB`: предсказания совпадают, разница log-вероятностей около 1e-13.
3. Исследовано влияние порога бинаризации `t` и параметра сглаживания `α` (5-кратная стратифицированная кросс-валидация на обучающей выборке).
4. Модель сравнена с Gaussian NB, Multinomial NB и логистической регрессией; выполнен анализ ошибок, параметры `θ` визуализированы как изображения 8×8.
5. На втором датасете показана бинаризация признаков разного масштаба по медиане (`MedianBinarizer`).
6. Разобраны ошибки предобработки: молчаливая бинаризация по нулю в `BernoulliNB` и утечка при подборе порогов вне конвейера.

## Используемые данные

Данные встроены в scikit-learn, скачивать ничего не нужно:

- `load_digits` — 1797 рукописных цифр 8×8, 64 признака (яркость 0…16), 10 классов. Разбиение 70/30 со стратификацией, `random_state=42`.
- `load_breast_cancer` — 569 объектов, 30 вещественных признаков, 2 класса.

## Полученные результаты

**Digits** (accuracy на тесте; по кросс-валидации подобраны порог `t = 7` и `α = 0.1`):

| Модель | test accuracy |
|---|---|
| Логистическая регрессия (бинарные признаки, t=7) | 0.922 |
| **Bernoulli NB (t=7, α=0.1)** | **0.885** |
| Multinomial NB (исходные признаки) | 0.876 |
| Bernoulli NB (t=0, α=1) | 0.841 |
| Gaussian NB (исходные признаки) | 0.822 |

- Качество сильно зависит от порога: при `t = 0` и `t = 15` изображение теряет форму (CV accuracy ≈ 0.85 и ≈ 0.71), максимум достигается в средней части диапазона.
- Очень малые и очень большие `α` ухудшают качество; оптимум находится между ними.
- Хуже всего распознаются цифры 1, 8 и 9, лучше всего 4, 6 и 0.

**Breast cancer** (бинаризация каждого признака по медиане обучающей выборки):

| Модель | test accuracy |
|---|---|
| Gaussian NB (исходные признаки) | 0.947 |
| Median-бинаризация + Bernoulli NB | 0.912 |
| Единый порог 0 + Bernoulli NB | 0.626 |

**Ошибки предобработки.** `BernoulliNB()` без параметра `binarize` молча использует порог 0 (на digits это 0.841 против 0.882 при осознанном пороге). Утечка медиан при подсчёте по всем данным заметного смещения на breast_cancer не дала (−0.3 п.п. при разбросе 0.8 п.п.), но настраивать предобработку принято внутри `Pipeline`.
