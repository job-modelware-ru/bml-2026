# Зависимость объяснённой дисперсии от числа компонент PCA

Герасимов Илья, 5030102/30401. Индивидуальное задание №49.

## Что нужно сделать

Задача работы: найти минимальное число главных компонент, которое сохраняет 90%, 95% и 99% дисперсии данных. Сначала разбираем простой пример из четырёх точек, потом проводим расчёт на Digits и Wine и сравниваем результаты.

## Какие данные используем

Оба набора входят в scikit-learn, отдельно скачивать их не нужно.

- **Digits:** 1797 изображений цифр. Каждое представлено 64 яркостями пикселей в одной шкале. Их масштаб оставляем как есть.
- **Wine:** 178 объектов с 13 химическими характеристиками. У признаков разные единицы измерения, поэтому перед PCA применяем `StandardScaler`. Отдельно проверяем, что получится без него.

Для каждого набора считаем все компоненты PCA и складываем их доли дисперсии. Так получаем кривую, по которой выбираем минимальное число компонент для каждого порога. Используем полное разложение SVD без whitening. Результаты дополнительно проверяю через собственные значения ковариационной матрицы.

## Что получилось

| Данные | Исходных признаков | k для 90% | k для 95% | k для 99% |
|---|---:|---:|---:|---:|
| Digits | 64 | 21 | 29 | 41 |
| Wine после стандартизации | 13 | 8 | 10 | 12 |

Без стандартизации первая компонента Wine объясняет 99,81% дисперсии. После стандартизации она даёт 36,20%. Значит, результат сильно зависит от масштаба признаков. При этом проценты считаются от разной общей дисперсии, поэтому по ним одним нельзя решить, какой вариант лучше сохранил полезную информацию.

Для выбора числа компонент сначала задаём нужный процент, затем находим первое пересечение этого порога на накопленной кривой.

В расчёте участвуют все объекты. Метки классов не используются. Сохранить 95% дисперсии не значит получить 95% точности. Если дальше нужна классификация, качество модели нужно проверить отдельно, а масштабирование и PCA обучать только на обучающей выборке.

## Как запустить

Нужен Python 3.12 или новее. Сначала из папки работы устанавливаем библиотеки:

```sh
python -m pip install -r requirements.txt
```

Потом открываем `src/solution.ipynb` в VS Code или Jupyter, выбираем это окружение Python и нажимаем **Run All**. Для запуска нужны только библиотеки из `requirements.txt`.

В ноутбуке уже сохранены таблицы и три графика, поэтому результаты можно посмотреть без повторного запуска. Там же находятся пояснения к расчётам, выводы и ссылки на описание методов и данных.
