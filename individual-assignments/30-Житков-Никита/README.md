# Применение ColumnTransformer к числовым и категориальным признакам

**Житков Никита, № 30. Основы машинного обучения.**

## Тема задания

Применение `ColumnTransformer` к табличным данным со смешанными типами признаков: сравнение стратегий предобработки и измерение штрафа за утечку данных при неправильном использовании препроцессора.

## Краткое описание решения

Собран единый `Pipeline`: `ColumnTransformer` → `LogisticRegression` / `RandomForest`. Числовая ветка — `SimpleImputer` + `StandardScaler`, категориальная — `SimpleImputer(fill_value='missing')` + один из кодировщиков (`OneHotEncoder` / `OrdinalEncoder` / `TargetEncoder`).

Сравнивались:

- две модели (LogReg, RandomForest) на трёх наборах;
- три стратегии импутации (`median`, `mean`, `KNNImputer(k=5)`);
- три кодировщика категорий (OHE, Ordinal, Target);
- корректный pipeline (fit только на `X_train`) vs некорректный (`ColumnTransformer.fit` на всём `X` до сплита) — на реальных данных и на синтетике с редкими категориями;
- `handle_unknown='ignore'` vs `'error'` при появлении новых категорий в тесте.

Оценка — 5-кратная стратифицированная кросс-валидация с фиксированным `StratifiedKFold(5, shuffle=True, random_state=42)`; все эксперименты используют одни и те же фолды, поэтому метрики сравнимы попарно. В ноутбуке встроены `assert`-проверки: scaler обучается только на тренировочной части, CV-фолды детерминированы.

## Используемые данные

| Набор | Объекты | Числовые | Категориальные | Пропуски | Класс |
|---|---:|---:|---:|---:|---|
| Titanic (OpenML `titanic`, v1) | 1 309 | 2 | 3 | 266 | выжил / не выжил |
| Adult (OpenML `adult`, v2) | 48 842 | 5 | 5 | 5 608 | доход >50K / ≤50K |

## Полученные результаты

**Базовая конфигурация, accuracy (5-fold CV):**

| Набор | LogisticRegression | RandomForest |
|---|---:|---:|
| Titanic | 0,782 ± 0,018 | 0,801 ± 0,024 |
| Adult | 0,851 ± 0,002 | 0,846 ± 0,003 |
| German Credit | 0,741 ± 0,019 | 0,765 ± 0,010 |

**Импутация.** На Adult все три стратегии идентичны (0,846). На Titanic `KNNImputer` даёт 0,796 против 0,801 у медианы — в пределах шума, но заметно дороже по времени. Дефолт — `median`.

**Кодировщики.** На Titanic (LogReg, кардинальность ≤3) все три эквивалентны в пределах шума. На Adult (RandomForest, кардинальность 5–16) `TargetEncoder` даёт 0,862 против 0,846 у OHE и 0,850 у Ordinal — устойчивый выигрыш за счёт компактного представления категорий.

**Утечка `TargetEncoder` (gap в п.п.):**

| Данные | correct (pipeline) | leaky (fit на всём X) | gap |
|---|---:|---:|---:|
| Adult | 0,850 | 0,850 | 0,033 |
| Titanic | 0,805 | 0,811 | 0,610 |
| Синтетика, 500 категорий по 6 объектов | 0,786 | 0,839 | 5,23 ± 1,23 |

На крупных данных с хорошо представленными категориями утечка почти не видна (gap 0,033 п.п. на Adult); на Titanic - 0,610 п.п.; на синтетике с редкими категориями gap вырастает до 5,23 +- 1,23 п.п. - в 8.6 раза больше, чем на Titanic, и в ~158 раз больше, чем на Adult. Правило "препроцессинг только внутри Pipeline" обязательно в любом случае.

**`handle_unknown`.** `'ignore'` сохраняет работоспособность (accuracy 0,796) при появлении двух неизвестных категорий в тесте (`'Z'` и `'missing'`). `'error'` падает с `ValueError`, перечисляя все неизвестные значения.

## Запуск

Из папки работы:

```bash
python -m pip install -r requirements.txt
```

Открыть `src/solution.ipynb` в VS Code с расширениями Python и Jupyter, выбрать окружение с установленными зависимостями, нажать **Run All**. Ноутбук скачивает наборы через `fetch_openml` (нужен интернет при первом запуске, дальше — кеш `~/scikit_learn_data`). Полный прогон — несколько минут. Готовые таблицы и графики сохранены в выводах ячеек: для просмотра отчёта повторный запуск не требуется.
