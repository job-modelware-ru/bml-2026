# Поиск аномалий во временном ряду с помощью скользящего z-score

## Цель

Исследовать поведение причинного скользящего z-score при различных типах отклонений и ошибках измерения: одиночных и соседних скачках, сдвиге уровня, дрейфе, изменении разброса, сезонности, зависании датчика и пропусках.

## Данные и метод

Используются девять синтетических сценариев по 240 почасовых наблюдений. Большинство построены на общем шумовом фоне; разметка аномалий условна. Демонстрационные данные содержат столбцы `scenario`, `step`, `time`, `value`, `label` и доступны в [CSV-файле](data/z_score_demo_data.csv). При запуске ноутбука данные также генерируются программно.

Функция `rolling_z_score(values, window)` возвращает знаковую оценку для каждого входного значения относительно предыдущего окна. Порог `abs(z) > 3` применяется отдельно. При недостатке истории, пропуске в окне или практически нулевом разбросе оценка неопределённа; бесконечные значения отклоняются. Исходные измерения не удаляются и не заменяются.

## Результаты

При размере окна 24 и пороге 3 получены следующие результаты:

| Сценарий | Результат |
|---|---|
| Контроль без внедрённых аномалий | 4 ложные тревоги среди 216 оценённых точек. |
| Два одиночных скачка | Обнаружены 2 из 2; дополнительно получены 3 ложные тревоги. |
| Два соседних скачка | Обнаружен 1 из 2: первый изменил статистики окна и скрыл второй. |
| Длительный сдвиг | Сигналы на 3 из 70 точек интервала; начало события обнаружено. |
| Дрейф | Сигналов внутри условно размеченного интервала нет. |
| Рост разброса | Сигналы на 5 из 70 точек интервала повышенного шума; событие обнаружено, но большинство изменённых точек не выделено. |
| Зависание датчика | Сигналов внутри интервала нет; 46 из 70 оценок неопределённы. |
| Шесть пропущенных измерений | Неопределённы 30 последовательных оценок, включая период восстановления окна. |
| Контекстная аномалия | В исходном ряду сигнал отсутствует; в остатках относительно значения 24 часа назад сигнал возникает. |

Эти результаты относятся только к заданным синтетическим сценариям и параметрам. Дополнительно рассматриваются поточечные и событийные метрики, задержка сигнала и сравнение с линейной регрессией.

## Выводы и ограничения

Метод подходит для первоначального обнаружения сильных отдельных отклонений при относительно стабильных локальных статистиках. Сам по себе он недостаточен для контроля пропусков, зависания датчика, длительных состояний, дрейфа и контекстных аномалий. Для практического применения требуются проверка качества данных, правила обработки неопределённых оценок, предметная разметка и оценка на будущих периодах.

Исследование выполнено на синтетических данных; для оценки эксплуатационного качества необходимы реальные размеченные ряды и независимый тест.

## Запуск

Проект представляет собой Jupyter Notebook с самостоятельной реализацией скользящего z-score, генерацией синтетических данных, визуализацией результатов и оценкой качества обнаружения аномалий.

### Вариант 1. Google Colab

1. Открыть [блокнот `src/solution.ipynb`](src/solution.ipynb).
2. Перейти в Google Colab: https://colab.research.google.com/.
3. Выбрать «Файл → Загрузить блокнот» и загрузить `solution.ipynb`.
4. Выполнить все ячейки через «Среда выполнения → Выполнить все».

Внешние данные и GPU не требуются. После выполнения создаётся файл `z_score_demo_data.csv`.

### Вариант 2. Локальный запуск в VS Code

**Требования:**
- Python 3.10 или новее.
- Visual Studio Code.
- Расширения Python и Jupyter для VS Code.

**Порядок запуска:**

1. Открыть папку `rolling-z-score` в VS Code.
2. Открыть терминал через `Terminal → New Terminal`.
3. Установить зависимости:

   ```bash
   py -m pip install -r requirements.txt
   ```

4. При необходимости установить Jupyter Kernel:

   ```bash
   py -m pip install ipykernel
   ```

5. Открыть файл `src/solution.ipynb`.
6. В правом верхнем углу выбрать установленный Python-интерпретатор (`Select Kernel`).
7. Нажать `Run All` для последовательного выполнения всех ячеек.

### Результаты выполнения

После запуска блокнот автоматически:

1. Генерирует девять синтетических временных рядов по 240 наблюдений.
2. Рассчитывает скользящие среднее, стандартное отклонение и z-score.
3. Определяет аномалии при заданном пороге.
4. Строит графики исходных данных и обнаруженных отклонений.
5. Вычисляет метрики качества обнаружения аномалий.
6. Проводит дополнительный эксперимент с линейной регрессией.
7. Создаёт CSV-файл с синтетическими данными.

Для воспроизведения основных экспериментов используется окно размером 24 наблюдения и порог `|z| > 3`.

Исходный код, формулы, графики и выводы представлены непосредственно в `src/solution.ipynb`.
