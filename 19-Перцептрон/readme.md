## Запуск численного примера

Из каталога `19-Перцептрон` выполните:

```bash
python3 src/numerical_example.py
```

Скрипт последовательно печатает:

1. Входные данные, начальные веса и целевой класс.
2. Взвешенную сумму `z = w1*x1 + w2*x2 + b`.
3. Значение ступенчатой функции активации.
4. Ошибку `error = y - y_hat`.
5. Новые веса после обновления.
6. Подробный лог обучения на наборе AND по эпохам.

## Использование класса

```python
import numpy as np
from src.perceptron import Perceptron

X = np.array([
    [0, 0],
    [0, 1],
    [1, 0],
    [1, 1],
])
y = np.array([0, 0, 0, 1])

model = Perceptron(learning_rate=0.1, n_epochs=20)
model.fit(X, y)

print(model.predict(X))  # [0 0 0 1]
print(model.score(X, y))  # 1.0
```

Метки классов должны быть равны 0 или 1. Если модель еще не обучена,
`predict` вызовет ошибку с просьбой сначала выполнить `fit`.

## Как работает алгоритм

Для объекта `x` считается взвешенная сумма:

```text
z = w1*x1 + w2*x2 + ... + wn*xn + b
```

Затем применяется ступенчатая функция активации:

```text
y_hat = 1, если z >= 0
y_hat = 0, если z < 0
```

Если ответ не совпал с правильным, веса и смещение обновляются:

```text
w_i = w_i + eta * (y - y_hat) * x_i
b   = b   + eta * (y - y_hat)
```

где `eta` — скорость обучения. Начальные веса равны нулю. Обучение
идет по эпохам и останавливается, когда за целую эпоху не было ни одной
ошибки, либо когда достигнуто максимальное число эпох `n_epochs`.

Для линейно разделимых данных перцептрон сходится. Для неразделимых
(например, XOR) гарантии сходимости нет: ошибки будут повторяться,
и модель остановится по лимиту эпох.
