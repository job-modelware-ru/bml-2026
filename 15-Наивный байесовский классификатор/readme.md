## Данные

Новости Lenta.ru (Kaggle):
https://www.kaggle.com/datasets/yutkin/corpus-of-russian-news-articles-from-lenta

Более 800 тысяч новостей за 1999–2019 годы. Используем заголовок (`title`) и рубрику (`topic`).

## Запуск кода

Python 3.12.

1. Если в `src/data/` уже есть `lenta_titles.csv`, ноутбук использует его.
   Иначе создайте `src/data/`, скачайте `lenta-ru-news.csv` по ссылке выше
   и положите его туда. Архив `.bz2` или `.zip` распаковывать не обязательно.
   Папка с данными исключена из Git.
2. Из папки темы установите зависимости и откройте ноутбук:

```bash
cd src
python -m pip install -r requirements.txt
python -m notebook naive_bayes.ipynb
```

При запуске на исходном CSV ноутбук создаёт `src/data/lenta_titles.csv` с нужными колонками.
