```bash

```

### 2. Запуск демонстрационного скрипта

```bash
python src/semi_supervised.py
```

## Что делает скрипт

1. **Численный пример (консоль).** Одна итерация самообучения на шести
   одномерных точках: по двум меткам учителя строятся центроиды, точки
   получают псевдометки по ближайшему центроиду, сомнительная точка
   отсекается порогом отступа, а разделяющая граница смещается с 5.50 на 5.75.
2. **Эксперимент на digits.** Размечено только 5% обучающей выборки
   (62 из 1257 объектов). Сравниваются: логистическая регрессия только на
   размеченных данных (0.835), SelfTrainingClassifier (0.909) и
   LabelSpreading (0.932); ориентир — модель на 100% меток (0.957).
3. **Кривая обучения.** Точность трёх подходов при доле разметки
   1–50% показывает, что неразмеченные данные ценнее всего при дефиците меток.
