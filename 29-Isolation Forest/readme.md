## Запуск кода

Проверено на Python 3.14. Команды выполняются из папки темы. Ручной пример использует только стандартную библиотеку.

```bash
python src/numeric_example.py
python -m pip install -r src/requirements.txt
python src/demo.py
```

Демо генерирует два облака нормальных наблюдений разной плотности и равномерно распределённые аномалии. Оба признака числовые. Генератор использует seed 42. Обучающая выборка содержит 660 точек, тестовая – 440. Масштабирование обучается на train отдельно внутри каждого pipeline. Метки отдельных наблюдений используются только для оценки на test. Доля внесённых аномалий известна заранее и используется для настройки моделей.

| Метод | Average Precision | ROC-AUC |
| --- | ---: | ---: |
| Isolation Forest | 0,788 | 0,938 |
| Local Outlier Factor | 0,666 | 0,928 |
| One-Class SVM | 0,687 | 0,911 |

При выбранном пороге Isolation Forest обнаруживает 28 из 40 аномалий и выдаёт 14 ложных тревог. Результаты относятся к одной синтетической выборке и указанным настройкам.
