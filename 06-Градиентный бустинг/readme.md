\## О проекте



В проекте реализован алгоритм градиентного бустинга для задачи регрессии.



Градиентный бустинг строит ансамбль моделей последовательно. Каждая следующая модель обучается на ошибках предыдущей композиции и постепенно улучшает итоговый прогноз.



В реализации используются:



\- решающие пни — деревья глубины 1;

\- среднеквадратичная ошибка (MSE);

\- числовые признаки;

\- коэффициент скорости обучения `learning\_rate`;

\- несколько последовательных итераций обучения.



Алгоритм реализован самостоятельно, без использования готовых моделей из библиотеки `sklearn`.



\## Основные этапы алгоритма



1\. Начальное предсказание вычисляется как среднее значение целевой переменной:



&#x20;  $$F\_0(x) = \\frac{1}{N}\\sum\_{i=1}^{N} y\_i$$



2\. Для каждого объекта вычисляется остаток:



&#x20;  $$r\_i = y\_i - F\_{m-1}(x\_i)$$



3\. Новый решающий пень обучается приближать эти остатки.



4\. Предсказание обновляется:



&#x20;  $$F\_m(x) = F\_{m-1}(x) + \\eta \\cdot h\_m(x)$$



&#x20;  где:



&#x20;  - $h\_m(x)$ — новый решающий пень;

&#x20;  - $\\eta$ — скорость обучения;

&#x20;  - $F\_m(x)$ — обновлённый прогноз.



\## Запуск программы



Для запуска используется Python версии 3.9 или выше.



Из корневой папки репозитория выполните:



```bash

python src/main.py

```



Если файл имеет другое имя, необходимо заменить `main.py` на фактическое имя файла.



\## Результаты работы



Программа выводит:



\- начальное предсказание;

\- количество построенных деревьев;

\- первые решающие пни;

\- значения MSE и RMSE;

\- тестовые предсказания;

\- изменение ошибки после различных итераций обучения.



\## Используемые библиотеки



Для реализации алгоритма используются только стандартные средства Python. Готовые модели из `sklearn` не применяются.
